## Pro 和 T1 差在哪：一条回国路由，两种超量逻辑

线路差异写具体一点。Pro 走的是电信 CN2 GIA、联通 AS9929、移动 CMI 的组合，官方英文描述是 "This profile includes Tier 1 + all Premium Transit providers, such as DMIT's backbone, and China Telecom CN2 GIA."。第三方回程测试显示，北京、上海、广东三网的回程都先从 AS906 进 AS23764 CTGNet，再经 AS4809 CN2 Backbone 落到各家运营商网络。延迟上，多家测评给电信约 60–80ms、联通 50–65ms、移动 50–60ms，另一份测评给的区间更窄（电信 60–70ms、联通 50–55ms、移动 50–55ms），口径略有出入，整体落在 50–80ms 是稳的。

T1 没有针对大陆做优化：电信联通走 NTT 双程，偶尔绕美国经 Lumen，移动走 CMI。国内访问能用，但晚高峰不保证。

真正的分水岭在超量策略。Pro 用完 500G 就停机，网站直接打不开，得等下一个计费周期或者临时升级套餐；T1 用完流量降速继续跑，WEE 降到 50Mbps，其余从 100Mbps 到 1Gbps 不等。一个跑内容是面向国内读者的博客，月流量冲到 600G 是很正常的事，这种情况下 Pro.TINY 会直接停服，而 T1.TINY 只是慢下来。反过来，如果你的站点访问者主要在国内，T1 的降速档位再高也救不了晚高峰的路由。

一句话归纳成决策规则：**国内访问速度是刚需就买 Pro，把流量预算留够；国内速度不是刚需就买 T1，享受不停机和更大的端口。**

## 下单前必须知道的四条限制

**退款有两个窗口，第一个被流量卡住。** 3 天内全额退款的前提是流量使用不超过 30GB；超过 30GB 就只剩 30 天内按剩余价值退款这一条路。30GB 对一台 1Gbps 端口的机器来说跑一次测速加几个下载就用掉大半，所以"3 天全额"实际是个很窄的窗口，能测的东西有限。退款可选原路返回（可能扣支付手续费）或退到账户余额（免手续费）。

**四类情况不予退款：** 续费订单、用余额支付的订单、同一系列产品退款累计达 3 次、IP 被封。IP 被封这一条值得单独留意，它意味着你不能靠"买来试试，封了就退"的方式反复操作。

**换 IP 有条件。** TYO Pro 系列在 IP 被墙的前提下，每 15 天可以免费换一次新 IP；其他原因换 IP 收 $5。

**默认 SSH 密钥登录。** 不熟悉密钥登录的人，需要看官方文档或者开工单让客服改成密码登录，这一步别等到买完才发现。

另外两条使用层面的提醒：DMIT 的维护不发邮件通知，偶尔会短暂失联，跑生产业务要自己有监控；付款支持支付宝、PayPal、信用卡，另有资料称支持微信，付完通常几分钟内收到开通邮件。

## 流媒体和联通用户：两个容易踩空的点

流媒体这块，不同测评的口径不完全一致。综合来看，Netflix 日区、Amazon Prime Video JP、YouTube Premium JP 在日本原生 IP 下可用，一份 2026 年 10 月的实测还列出了 TikTok、Disney+、Reddit、ChatGPT 均识别为日本区原生解锁。但 Abema、Hulu Japan 这类服务不一定，有测评明确说需要额外配置。如果你的用途就是看 Abema，别把它当成买 Pro 的理由，先跟客服确认。

联通用户有个实操点：V4 去程偶尔会绕香港，速度有时不理想，V6 路由是直连的，表现更好。开机之后先把 IPv6 配上，体验差别明显。
